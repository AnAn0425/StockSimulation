# 💸 終端機股市觀測站：5000萬虛擬資金大戶模擬交易系統

本專案為物件導向程式設計（C++）期末專題。實作了一款基於 Windows 控制台的即時動態股票模擬交易系統。使用者擁有 5,000 萬的初始虛擬資金，可在秒級即時跳動的市場中針對熱門高價股進行買賣操盤。

## 🛠️ C++ 核心技術實現（期末指標對照）

1. **類別繼承功能 (Inheritance)**
   - 宣告基底類別 `FinancialProduct` 作為核心架構。衍生出 `Stock`（普通股票）類別，並覆寫虛擬函式 `updatePrice()` 以實作股價隨機波動。
2. **檔案讀寫功能 (File I/O)**
   - 整合 `<fstream>` 庫，程式啟動時自動讀取 `stock_saveData.txt` 載入資產；關閉系統前會自動覆寫檔案進行資料持久化。
3. **標準模板庫應用 (STL Containers)**
   - 使用 `std::vector` 與 `std::unique_ptr` 動態管理市場商品，防止記憶體洩漏。
   - 使用 `std::map<string, int>` 實作玩家的持股庫存。
4. **多執行緒即時看盤 UI (Multi-threading)**
   - 引入 `<thread>` 與 `<mutex>` 技術，開啟背景執行緒每隔 1.5 秒自動重新計算股價並刷洗終端機畫面，達成免操作、即時動態閃爍的真實股市看盤效果。
